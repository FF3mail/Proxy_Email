# 2. Системные требования

## 2.1. Поддерживаемые платформы

| Параметр | Минимум | Рекомендуется (пилот) | Примечание |
|----------|---------|----------------------|------------|
| ОС | Debian 11+ / Ubuntu 20.04+ | Ubuntu 24.04 LTS | Проверено на Ubuntu 24.04 + PHP 8.3 |
| RAM | 4 ГБ | 8 ГБ и более | 20 IMAP + 20 SMTP воркеров, пик при больших вложениях |
| CPU | 2 ядра | 4 ядра | |
| Диск | 40 ГБ SSD | 100+ ГБ SSD | Maildir + логи + БД |
| Сеть | Стабильный исходящий SMTP/IMAP | | Firewall должен пропускать 443 (панель), 25/587/993 к внешним провайдерам |

> **Комментарий:** staging на 8 ГБ RAM **не является** эталоном для production с сотнями референтов. Оцените нагрузку отдельно.

---

## 2.2. Предустановленный почтовый стек

DELTA-transit **не заменяет** полноценный почтовый сервер. Он устанавливается **поверх** существующего стека:

- **Postfix** — локальная доставка на `:25`
- **Dovecot** — IMAP и Maildir
- **MariaDB** — общая или выделенная БД `mail_proxy`
- **Nginx** — веб-сервер для панели

Типичный сценарий: сервер уже развёрнут с **iRedMail**, созданы тестовые ящики, работает доставка локальной почты.

### Проверка базового стека до установки DELTA-transit

```bash
systemctl is-active postfix dovecot mariadb nginx
postconf myhostname
doveconf mail_location
```

Если Postfix или Dovecot не активны — сначала восстановите базовую почту, иначе прокси не сможет доставлять письма.

## 2.3. Программные зависимости

Инсталлятор `delta-transit-install.sh` устанавливает пакеты при необходимости:

| Пакет | Назначение |
|-------|------------|
| `python3`, `python3-venv`, `python3-pip` | Демон |
| `mariadb-server` | База `mail_proxy` |
| `nginx` | Веб-панель |
| `postfix`, `dovecot-imapd` | Локальная почта |
| `php-fpm` | PHP 8.1–8.3 (автоопределение) |
| `logrotate`, `openssl`, `curl` | Ротация логов, TLS |

Python-зависимости из `requirements.txt` ставятся в venv `/opt/delta-transit/venv/`.

## 2.4. Пользователь vmail и каталог /var/vmail

Демон работает от **`vmail`**, не от выдуманного `mailproxy`.

На iRedMail каталог `/var/vmail` часто имеет владельца **`root:root`** и права `0755`. Инсталлятор при «усилении» прав (`chmod o-rwx`) **проверяет владельца** и **отказывается** менять права, если владелец не совпадает с пользователем Dovecot (`doveconf mail_uid` / `mail_gid`).

**Действие администратора:** если инсталлятор сообщает об ошибке владельца `/var/vmail`, согласуйте владельца с документацией iRedMail или явно выполните `chown vmail:vmail /var/vmail` **осознанно**, понимая последствия для вашей схемы бэкапов.

## 2.5. Сетевые и DNS-требования

### Hostname и DNS

- Корректный **hostname** сервера (`hostnamectl`)
- **NTP/chrony** — для OAuth2 и TLS-сертификатов
- **PTR-запись** (обратный DNS) — желательна для исходящей почты через внешний SMTP

### URL веб-панели

При установке запрашивается **публичный HTTPS-URL** панели (`PARAM_APP_URL`), например:

```
https://panel.mail.example.com
```

Требования:

- Схема **обязательно HTTPS**
- Hostname панели **не должен совпадать** с `myhostname` Postfix
- URL записывается в `web/config.php` как `APP_BASE_URL` (для OAuth redirect)

### Доступ к панели

По умолчанию панель отвечает только клиентам из **частных IP-сетей**. Для удалённого администрирования используйте VPN или SSH-туннель — см. [08-security.md](08-security.md).

## 2.6. MariaDB

- База: `mail_proxy` (создаётся из `schema.sql`)
- Пользователь: `mail_proxy` (пароль генерируется при установке)
- Файл секретов: `/etc/mail-proxy/install-secrets.txt` (только root, после установки)

Пароль БД также в `/etc/mail-proxy/db.conf` в секции `[db]`.

---

## 2.7. PHP-FPM

- Минимальная версия: **PHP 8.1**
- На staging по умолчанию `pm.max_children = 10` (~8 ГБ RAM)
- Переопределение перед установкой:

```bash
export PHP_FPM_MAX_CHILDREN=15
./delta-transit-install.sh
```

`memory_limit` в PHP: **512M** на запрос (не резервируется постоянно).

---

## 2.8. Порты и firewall

| Направление | Порт | Назначение |
|-------------|------|------------|
| Входящий (локально) | 25 | Postfix — демон доставляет сюда |
| Входящий | 443 | HTTPS веб-панели |
| Исходящий | 993, 587, 465 | IMAP/SMTP к внешним провайдерам |
| Исходящий | 443 | OAuth token endpoints |

Убедитесь, что исходящие соединения к почтовым провайдерам не блокируются корпоративным firewall.

---

## 2.9. Права root

Установка и `configure_limits.sh` выполняются **только от root**. После установки повседневная работа — от обычного администратора с `sudo` для `systemctl`, просмотра логов и бэкапов.

---

## 2.10. Чек-лист готовности хоста

- [ ] Linux обновлён, время синхронизировано
- [ ] Postfix + Dovecot + MariaDB работают
- [ ] Создан хотя бы один тестовый ящик в Maildir
- [ ] Есть свободное место на диске (≥ 20 ГБ под логи и почту)
- [ ] Определён HTTPS-URL панели (отличный от hostname почты)
- [ ] Есть root-доступ и копия репозитория на сервере
