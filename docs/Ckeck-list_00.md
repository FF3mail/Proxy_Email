# Чек-лист развертывания DELTA-transit v3.3 (Пилотная эксплуатация)

> Синхронизирован с [DELTA-transit_anchor.md](DELTA-transit_anchor.md) v3.3.

## 1. Подготовка ОС

- [ ] Поддерживаемая версия Linux установлена
- [ ] Установлены все обновления безопасности
- [ ] Настроена синхронизация времени (NTP/chrony)
- [ ] Корректно настроен hostname
- [ ] Проверено DNS-разрешение

Проверка:

```bash
hostnamectl
timedatectl
resolvectl status
```

## 2. Пользователь сервиса

- [ ] Создан пользователь mailproxy
- [ ] Вход в shell запрещён
- [ ] Домашний каталог существует
- [ ] Владельцем рабочих каталогов является mailproxy

Проверка:

```bash
id mailproxy
ls -la /opt/mail-proxy
```

## 3. Структура каталогов

- [ ] Существует каталог /opt/mail-proxy
- [ ] Существует каталог /var/lib/mail-proxy
- [ ] Существует каталог /var/log/mail-proxy
- [ ] Существует каталог /etc/mail-proxy
- [ ] Отсутствуют каталоги с правами 777
- [ ] Ключи доступны только сервисному аккаунту

Проверка:

```bash
find /opt/mail-proxy -type d -ls
```

## 4. Python-окружение

- [ ] Установлена требуемая версия Python
- [ ] Установлены все зависимости

## 5. MariaDB

Проверка FIX P7 (на staging, после вставки тестовой записи с недопустимым значением):


- [ ] Все сервисы запускаются после reboot
