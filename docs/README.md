# Документация DELTA-transit

Навигация по каталогу `docs/`. Это **индекс**, а не дубликат глав руководства оператора.

> **Авторитетный источник требований:** [`docs/SPEC.md`](SPEC.md) (SPEC §0.1 и решение D-00: единственный якорь). [`docs/DELTA-transit_anchor.md`](DELTA-transit_anchor.md) — указатель и не задаёт требований.

**Правила для AI/агентов:** требования проекта задаёт `docs/SPEC.md`. Каталоги `reports/` и `prompts/` — только история и не являются источником требований. Расхождение кода или скриптов установки с `docs/SPEC.md` записывается в реестр расхождений (раздел 13) и не исправляется молча.
