Проведи локальное исправление дефекта валидации.

Контекст:

Настройки:

auth_type
smtp_encryption
imap_encryption

читаются из БД и используются без проверки допустимых значений.

Требуется добавить whitelist-проверку.

ЖЁСТКИЕ ОГРАНИЧЕНИЯ:

1. НЕ менять архитектуру проекта.
2. НЕ выполнять рефакторинг.
3. НЕ менять структуру БД.
4. НЕ создавать новые таблицы.
5. НЕ менять интерфейсы функций.
6. НЕ добавлять новые зависимости.
7. НЕ создавать новые файлы.
8. НЕ переносить код между модулями.
9. НЕ менять бизнес-логику кроме валидации.
10. Если требуется архитектурное изменение — остановиться.

Требуемое поведение:

auth_type:
- password
- oauth2

smtp_encryption:
- ssl
- tls
- none

imap_encryption:
- ssl
- tls
- none

Для неизвестных значений:

- записывать ошибку в лог
- безопасно завершать обработку текущего аккаунта
- не использовать значение по умолчанию молча

Формат ответа:

1. Причина дефекта.
2. Минимальный patch.
3. Возможные побочные эффекты.
4. Регрессионные тесты.

Запрещено создавать новую систему конфигурации.
